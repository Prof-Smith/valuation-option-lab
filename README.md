# Valuation-to-Option Pricing Lab UX Refresh

This package preserves the notebook-to-JSON-to-dashboard workflow and adds a guided, accessible student experience.

## Refresh the repository

1. Back up the current repository or create a branch.
2. Copy the package contents into the repository root, preserving `.github`, `data`, and `docs`.
3. Replace the demonstration CSV values and source notes with documented company data.
4. Commit and push. The GitHub Actions workflow executes the notebook and publishes `docs`.
5. In **Settings > Pages**, select **GitHub Actions** if it is not already selected.

## UX additions

- Start Here orientation and two-track model framing
- Reorganized KPI hierarchy
- Five-stage progressive navigation
- Horizon-alignment banner
- Expandable validation diagnostics
- Accessible redundant chart markers
- Downloadable Plotly charts and underlying-value view
- Memo evidence copier and submission checklist
- Actionable load-error guidance

The included Asteron Systems values are demonstration data and must be replaced for a real submission.
